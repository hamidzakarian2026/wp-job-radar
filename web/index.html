اتصال به گیت‌هاب

برای اجرای دستی از این صفحه، یک توکن گیت‌هاب لازم است. توکن فقط در همین مرورگر ذخیره می‌شود و بدون آن هیچ‌کس نمی‌تواند از این صفحه چیزی اجرا کند.
  1. صفحه‌ی ساخت توکن را باز کن (Fine-grained).
  2. در Repository access فقط wp-job-radar را انتخاب کن.
  3. در Permissions دسترسی Actions: Read and write را بده.
  4. توکن را بساز، کپی کن و اینجا بگذار.
