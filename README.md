# wp-job-radar

رادار آگهی‌های استخدام وردپرس و طراحی سایت. هر ساعت جابینجا، جاب‌ویژن و ایران‌تلنت را اسکن می‌کند و آگهی‌های جدید و مرتبط را به کانال تلگرام می‌فرستد. همه‌چیز روی GitHub Actions اجرا می‌شود و رایگان است.

## چطور کار می‌کند

| بخش | کار |
|---|---|
| `scan.yml` | هر ساعت (دقیقه‌ی ۱۷) اسکن می‌کند، آگهی‌های جدید را فیلتر و به کانال می‌فرستد |
| `buttons.yml` | هر ۵ دقیقه کلیک‌های دکمه‌ی «ارسال رزومه» را پردازش می‌کند (فقط وقتی کوکی/توکن سایت‌ها تنظیم شده باشد) |
| `pages.yml` | صفحه‌ی تست را روی GitHub Pages منتشر می‌کند |
| `data/` | وضعیت: آگهی‌های دیده‌شده، ارسال‌شده، رزومه‌های ارسالی و گزارش آخرین اجرا |

**فیلتر مرتبط بودن:** آگهی وقتی ارسال می‌شود که در عنوانش وردپرس/ووکامرس/المنتور یا «طراح سایت/وب‌سایت» باشد، یا در متنش این کلمات باشد و عنوانش یک شغل وب باشد (نه سئو، گرافیک، مارکتینگ و…).

## Secrets (Settings → Secrets and variables → Actions)

| نام | لازم؟ | مقدار |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | بله | توکن ربات |
| `TELEGRAM_CHAT_ID` | بله | `@username` کانال یا آیدی عددی `-100…` |
| `IRANTALENT_TOKEN` | اختیاری | مقدار کوکی `auth_token_irantalent_new` (در Console سایت ایران‌تلنت: `copy(decodeURIComponent(document.cookie.match(/auth_token_irantalent_new=([^;]+)/)[1]))`) |

با تنظیم `IRANTALENT_TOKEN`، دکمه‌ی «ارسال رزومه» آگهی‌های ایران‌تلنت خودکار می‌شود: کلیک ← چند دقیقه بعد رزومه ارسال و دکمه به «✅ رزومه ارسال شد» تغییر می‌کند. بقیه‌ی آگهی‌ها دکمه‌ی مستقیم صفحه‌ی ارسال رزومه در سایت را دارند. جاب‌ویژن توکن ۲۴ ساعته دارد و ارسال خودکار ندارد.

**جابینجا:** پشت ArvanCloud است و به سرورهای گیت‌هاب (خارج از ایران) پاسخ 403 می‌دهد، پس روی Actions غیرفعال است. کد آن کامل است و اگر اسکنر روی سیستمی در ایران اجرا شود با `JOBINJA_ENABLED=1` (و برای ارسال خودکار `JOBINJA_COOKIE`) فعال می‌شود.

## اجرای دستی

- از صفحه‌ی تست (GitHub Pages) یا
- Actions → Scan jobs → Run workflow: `test` (ارسال N آگهی آخر امروز)، `scan` (اسکن عادی)، `dry` (فقط گزارش در لاگ)

## اجرای محلی

```bash
pip install -r requirements.txt
python scan.py --mode dry
```
